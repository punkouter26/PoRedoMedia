UI consolidation: U1–U10

Before and after, captured headless with Playwright at 1366×860 (desktop) and 390×844 (phone), Test environment with mock AI, the same seeded user in both, on 2026-10-21. Effects are off in automated browsers, so the spectrogram ribbons on Sounds do not show here. The orange strip is the mock-data notice, shown only with mock AI.

RuntimeDefects found by inspecting the live routes

  • Focus box on every page title. Navigation focuses the H1 for screen readers, and the browser drew a hard black outline around it (visible in every "before" shot). Headings now take focus without a ring.
  • Squashed Run button on phones. The button shrank to a vertical "R U N" column next to a long summary. It now keeps its shape.
  • Icon styles that never applied. Radzen 12 renders icons as i.rzi, so rules written for .rz-icon matched nothing: the run steps' green/red/spinning icons, the gallery badge icons. They work now.
  • AI-model label over its value. "Automatic" is an empty value, so the floating label sat on top of it. The label is now fixed above the field.
  • Header on two rows on phones, and four toolbar rows before the first gallery thumbnail.

U1One account menu, and a tab bar on phones

Settings, the user's name and Sign out became one avatar button that opens a side drawer. On phones the navigation moves to a bottom tab bar (Create, Library, Runs), and the header is a single row.

U2One command bar on the gallery

Search (with its icon inside), kind filter, sort as an icon menu and Add, in one sticky bar. The Select toggle is gone: each card has a tick box, and while anything is ticked the bar becomes the bulk-action bar.

U3Library: My media, Sounds and Feed on one page

One page with three sections that keep their own addresses (/gallery, /sounds, /feed), so links and bookmarks still work. The main navigation drops from four links to two.

U4Sounds as cards

The 5-column data grid became cards: play, name, length, star and delete in one row, tags below, spectrogram filling the width when effects are on. Paged at 24, with a sort menu.

U5Detail panel: one primary action, icons, and sharing inline

"Use as source" is the one primary button. Compare, Download, Share, Pin and Delete are icons, and Copy, GIF and Roast audio go in a ⋯ menu. Share opens a section inside the panel instead of a dialog on top of it.

U6Function tiles and a two-column composer

Functions are icon tiles (the whole tile ticks). On wide screens their settings sit in a column beside them, and each settings group can be collapsed. Saved recipes are one-tap chips. While a run goes, "Start something else" leaves it running.

U7A run center in place of the tray popup

A side drawer with live progress bars and View, Again and Cancel for every recent run. The end-of-run toast is skipped when that run is already on screen.

U8Home overview

Create's start page shows today's runs left with the dial, what this tab has spent, the latest runs and a peek at the trending feed, beside the drop zone. Recent media is a single row that scrolls sideways.

U9Design-system cleanup

  • The hand-built popups (.shell-popup, .pop-scrim) are replaced by Radzen side dialogs.
  • Links that borrowed Radzen's internal rz-button classes (Remix, Use as source, the file picker) now use one LinkButton/.po-link-btn style built from theme variables.
  • Breakpoints are unified to 720px (phone) and 1024px (single column); 800px and 900px are gone.
  • The mock-data alert is now a thin strip; page titles are smaller and share a row with their tabs.
  • The gallery tick box is a 24px target: the WCAG 2.2 scan caught the first version at 20.8px.
